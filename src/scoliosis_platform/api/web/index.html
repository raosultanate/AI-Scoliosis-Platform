Behind the answer

How Cobb-angle analysis works

The final product will turn a complex medical measurement into four understandable steps.

  1. 1

    Add an X-ray

    A front-facing spine X-ray is prepared for analysis.

  2. 2

    Find vertebrae

    A vision model locates the corners of each vertebra.

  3. 3

    Measure the curve

    The software selects endplates and calculates their angle.

  4. 4

    Explain the result

    You see the angle, selected bones, and an annotated image.

+

A helpful explanation—not a diagnosis

SpineAngle is research software under development. A Cobb angle should be reviewed by a qualified clinician and must not be used alone for treatment decisions.
